# «Адал азамат» — 6-сынып сынып сағаттары (2026–2027 оқу жылы)

6-сыныпқа арналған 34 сынып сағатының интерактивті сайты және ҚМЖ-лары (Word).

## Құрамы

| Папка / файл | Сипаттамасы |
|---|---|
| `index.html` | Сайт: 34 сабақ, теория, ойындар (викторина, шын/жалған, сәйкестендір, әріп шашу, сиқырлы шаңырақ), 3 тапсырма, С деңгейі, үй тапсырмасы, бейнелер, кері байланыс |
| `kmzh/2-bettik/` | ҚМЖ — 1-нұсқа (әр сабақ 2 бет), 34 бөлек файл + `QMZh_barlygy_34.docx` |
| `kmzh/zhana-ulgi/` | ҚМЖ — жаңа үлгі бойынша (Кіріспе, Негізгі бөлім, Қауіпсіздік сабағы, Қорытынды), 34 бөлек файл + `QMZh_barlygy_34.docx` |
| `src/` | Сабақтардың мазмұны (`lessons.json`, `d01.py`–`d07.py`) және сайт пен Word файлдарын жасайтын скрипттер |

## Сайтты GitHub Pages арқылы ашу

1. Репозиторийге осы папканың ішіндегі барлық файлды жүктеңіз.
2. **Settings → Pages** бөлімінде **Branch: main**, папка **/(root)** таңдап, **Save** басыңыз.
3. 1–2 минуттан кейін сайт `https://<сіздің-логин>.github.io/<репозиторий>/` мекенжайында ашылады.

Сайт бір `index.html` файлынан тұрады, сервер қажет емес. Кері байланыс пен үй тапсырмасының белгілері әр оқушының браузерінде сақталады.
